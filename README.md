# 🍏 Miam - Planificateur de Repas Intelligent

**Miam** est une application multiplateforme (Android, Windows, Web/PWA) conçue pour simplifier la gestion des repas au quotidien. Elle permet de découvrir de nouvelles recettes de manière ludique, de planifier sa semaine en un clic, et de générer automatiquement une liste de courses intelligente.

L'application fonctionne **100% hors-ligne**, garantissant la confidentialité absolue de vos données.

## ✨ Fonctionnalités Principales

* 🗓️ **Planificateur Automatique & Manuel :** Générez une semaine de repas complète en respectant vos contraintes (ingrédients bannis ou imposés, nombre de convives) ou choisissez vos plats manuellement.
* 🔥 **Découverte par Swipe :** Un mode "Tinder-like" pour aimer de nouvelles recettes ou bannir définitivement des ingrédients de votre alimentation.
* 📖 **Carnet de Recettes Personnalisé :** Créez, modifiez et stockez vos propres plats avec gestion des macros (Légumes, Protéines, Féculents).
* 🛒 **Liste de Courses Intelligente :** Les ingrédients des repas planifiés sont automatiquement calculés et triés par rayon de supermarché.
* 💾 **Sauvegarde Locale & Autonome :** Aucune base de données cloud requise. Tout est stocké directement sur votre appareil.
* 🔄 **Import / Export JSON :** Sauvegardez, restaurez et partagez vos carnets de recettes et plannings avec vos amis. L'importation fusionne intelligemment les nouvelles recettes sans créer de doublons.
* 🌙 **Mode Sombre Intégré :** Interface ergonomique et agréable de jour comme de nuit.

## 🚀 Installation & Lancement

Ce projet est développé avec [Flutter](https://flutter.dev). Pour l'exécuter localement, assurez-vous d'avoir installé le SDK Flutter.

**1. Cloner le dépôt et installer les dépendances :**
```bash
git clone [https://github.com/ToineLey/miam.git](https://github.com/ToineLey/miam.git)
cd miam
flutter pub get
```
